# 🎵 Spotify Clone (Frontend)

A responsive Spotify web UI clone built using **HTML**, **CSS**, and **JavaScript**.  
This project mimics the look and basic functionality of the Spotify music player (UI only, no backend/audio streaming).

---

## 📸 Preview



---

## 🚀 Features

- 🎨 Modern and responsive Spotify-style UI
- 🎵 Play/pause song preview animation (UI simulation)
- 🎚️ Volume and playback controls (non-functional)
- 📱 Fully responsive layout for mobile, tablet, and desktop
- ⚡ Smooth transitions and interactions with JavaScript

---

## 💡 Technologies Used

| Tech         | Purpose                         |
|--------------|----------------------------------|
| HTML         | Structure of the app             |
| CSS          | Styling and layout               |
| JavaScript   | DOM interaction and animations   |
| Font Awesome | Icons for UI controls            |
